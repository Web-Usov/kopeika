# Дорожная карта «Копейки»

План и решения владельца в одном месте. Читать перед новой задачей. Подробности — в issues и спецификациях, здесь только суть.

## Принципы

- Основной учёт бесплатный, без лимитов и без рекламы.
- Деньги (Stars) пока не обсуждаем, это позже.
- Фото чеков не храним.
- Два языка: русский и английский.
- Данных о людях собираем минимум.
