# Индекс стандартов: ссылки, а не новая спецификация

`.taskflow/standards/index.json` начинается пустым: `{ "version": 1, "entries": [] }`.
Запись: `{ "id": "existing-rule", "title": "Название", "description": "Область применения", "path": ".taskflow/existing.md", "areas": ["api"], "tags": ["testing"], "status": "draft" }`.
`areas`, `tags`, `description` необязательны. Несколько записей могут ссылаться на один файл.

Ссылайтесь на существующие AGENTS.md, спецификации и ADR; не копируйте бизнес-требования.
Наблюдения из кода — только предложения с примерами, исключениями и вопросом «почему».
Они не отменяют AGENTS/spec/ADR и ограничения прав. Изменения пишет только planner на ветке `plan/<slug>` после явного подтверждения человека; PR сливает человек.
Новые предложения остаются `draft`, пока человек явно не одобрит их. Поле `approved` — подсказка маршрутизации, НЕ подтверждённая системой личность или подпись человека.

`tf_standards`: `list`, `suggest`, `load` с точными `ids`, `check`. Подсказки не выбирают записи автоматически.
Черновики доступны только явно (`includeDrafts: true`) для обсуждения, не для implementer/reviewer/qa.
Задача может содержать `standards: [existing-rule]`; старые задачи без поля работают без индекса.
В dispatch implementer и reviewer получают выбранные ссылки из worktree задачи, включая контрольные суммы; ошибочная привязка останавливает запуск.

Настройки `standards`: `index`, `roots` ([".taskflow","docs","AGENTS.md"]), `maxContextChars` (24000).
Пути только относительные внутри репозитория и разрешённых корней; документация `.md`, `.txt`, `.rst`, `.adoc`. Скрытые файлы, секреты, игнорируемые Git файлы, node_modules и выход через symlink запрещены. Единственное исключение — верхнеуровневый `.taskflow`, явно включённый в разрешённые корни; скрытые дочерние сегменты всё равно запрещены. Сеть не используется.
Бюджет включает заголовки и содержимое; превышение — ошибка без частичной загрузки или обрезки. Большой источник лучше разделить в его каноническом месте, не делать копию ради индекса.

До декомпозиции уточните требования: цель, не-цели, примеры, крайние случаи, критерии приёмки и проверки, ссылки на код/дизайн, стандарты и открытые решения.
Planner сохраняет `.taskflow/plans/<slug>/shape.md` с явными разделами «Черновик», «Открытые вопросы», «Подтверждение человека». Молчание не означает согласия; локальная отметка — только метаданные процесса. Спецификации не меняются молча.
