# Копейка: гайд по маскоту

Короткие правила, чтобы Копейка везде выглядела и говорила одинаково.

## Кто она

- **Имя:** Копейка. Женский род, «она».
- **Образ:** пиксельная медная монетка с лицом, ручками и ножками. Чеканный ободок: светлый верх, тёмный низ, кольцо бусин, видимый торец. Характер передают лицо, жесты и движение. Предметы в руках пока не используем.
- **Характер:** добрая педантка. Считает «до копейки», но никогда не упрекает и не стыдит. Тёплая, чуть старомодная, с лёгким юмором.
- **Как говорит:** коротко и ясно, по-человечески, без канцелярита. Шутит мягко и не про чужие долги. Если что-то пошло не так, не винит человека, а предлагает, что делать дальше.
- **Слоганы:**
  - Делим до копейки
  - Копейка дружбу бережёт
  - Ни копейки долга
- **История для текстов, не для рисунка:** слово «копейка» от «копьё», на новгородских монетах 1535 года был всадник с копьём. На картинках копья нет.

## Пиксель-арт

Спрайт 56×54, 9 цветов, честная сетка: каждая клетка одного цвета, без сглаживания и полупрозрачности.

- **Масштаб только целый:** ×1, ×2, ×3… В вебе — `image-rendering: pixelated`, размер элемента кратен 56×54 (например, 112×108 или 168×162 CSS px). Дробное увеличение размывает пиксели.
- **Тёмная тема:** отдельный атлас `kopeika-dark.png` — светлый блик по контуру сверху-слева и тёмная медь по остальному контуру, иначе силуэт тонет в фоне `#17212b`.
- **Движение:** анимации кадровые, длительности кадров — в `kopeika.json`. Уважаем `prefers-reduced-motion`: показываем статичную эмоцию.

## Образы и анимации

| Эмоция | Анимация | Где использовать |
|---|---|---|
| `greeting` — привет | `wave` — машет; `idle` — покой с дыханием и морганием | Home, онбординг, аватар бота (только монета), картинка Mini App |
| `settled` — все в расчёте | `settled` — покачивается, искорки мерцают | баланс и карточка группы, когда все в расчёте |
| `thinking` — задумалась | `thinking` — мысли-монетки появляются по одной | пустые экраны: нет групп, нет трат |
| `worried` — неловко | `worried` — дрожь и капля пота | большие долги. Сочувствие, не испуг |
| `oops` — ой, ошибка | `oops` — подскок, ладони вверх | «что-то пошло не так», ошибки сети и API |
| `celebrate` — ура | `celebrate` — прыжок с искорками | оверлей в момент, когда группа переходит в расчёт (#22); стикер от бота (#23) |
| — | `spin` — поворот на ребро | загрузка |

Правило выбора: образ отвечает настроению экрана. Тревогу показываем рядом с долгом, но текст при этом остаётся добрым и без упрёка.

## Охранное поле и размеры

**Охранное поле** — свободное место вокруг фигуры со всех сторон. Текст, края экрана и другие картинки в него не заходят.

| Где | Поле |
|---|---|
| Бренд-материалы: картинка Mini App, стикеры, промо (аватар — монета в край, без поля) | ¼ ширины монеты |
| Интерфейс: Home, пустые состояния, оверлеи | ⅛ ширины монеты, но не меньше 8 px |

**Размеры в интерфейсе:**

| Что | Масштаб |
|---|---|
| Пустые состояния, Home, оверлеи | ×2 (112×108) или ×3 (168×162) |
| Мелкие места (строка списка, тост) | ×1 (56×54) — только силуэт и глаза, эмоцию передаём текстом |
| Меньше ×1 | только favicon (`brand/favicon.svg`, 16×16, работает до 16 px) |

## Запреты

- Оружие, доспехи, шлемы, любая военная атрибутика (никаких копий и всадников).
- Дробное масштабирование, сглаживание, растягивание по одной оси.
- Менять цвет монеты, перекрашивать под тему или акцент, добавлять цвета в спрайт.
- Упрёки и стыд в репликах. Никаких «опять ты должен», «ну сколько можно». Копейка поддерживает, а не стыдит.
- Эффекты поверх фигуры: тени, фильтры, градиенты, текст.
- Добавлять предметы в руки, пока это не решено отдельно.

## Файлы

**Для продукта** — `web/public/brand/`:
- `favicon.svg` (16×16 из `<rect>`), `favicon-32.png`, `apple-touch-icon-180.png`
- `bot-avatar-640.png` — аватар бота: круглая монета «в край» без рук и ног, фон цвета контура (Telegram режет аватар в круг, монета заполняет его целиком)
- `miniapp-640x360.png` — картинка Mini App для @BotFather
- `mascot/kopeika.png`, `mascot/kopeika-dark.png` — атлас всех кадров в 1×, ячейки 56×54
- `mascot/kopeika.json` — `{cell, animations: {имя: [{x, y, ms}]}, emotions: {имя: {x, y}}}`

**Исходники** — `design/mascot/pixel/`:
- `sprite.py` — персонаж как данные: тело, лица, руки, позы
- `build.py` — атласы, json и превью: `uv run --with pillow python design/mascot/pixel/build.py`
- `brand.py` — favicon, аватар, картинка Mini App: `uv run --with pillow python design/mascot/pixel/brand.py`
- `stickers.py` — стикеры Telegram (после `build.py`): `uv run --with pillow --with imageio-ffmpeg python design/mascot/pixel/stickers.py`
- `stickers/` — статичные 512×512 (png, webp) и видеостикеры WEBM (VP9 с альфой, ≤ 3 с), в сборку приложения не входят
- `preview/` — листы, раскадровка и GIF для людей

Руками PNG не правим: меняем `sprite.py` и пересобираем.

**Архив** — первая, иллюстрированная версия Копейки (концепт, шесть образов, мастера 1600 px с прозрачным фоном, SVG, стикеры, анимации, бренд-картинки и скрипты): в репозитории её нет, она лежит zip-файлом в черновике релиза «Архив: иллюстрированная Копейка» на GitHub (Releases). В продукт не идёт, мастера можно использовать для промо. Черновик не публиковать: тег попадёт в версию приложения (`git describe --tags`).
