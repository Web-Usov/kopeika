Копейка: единый риг

Лицо из A, эффекты из B, блеск из C — в одном SVG. Нажмите эмоцию: Копейка плавно перейдёт в неё, тип глаза меняется через моргание, эффекты проступают и гаснут. На большой монете всё время идёт фоновый блеск покоя, дыхание и автоморгание.

Как устроено

Слои внутри монеты снизу вверх: монета без вшитых бликов → тонировки (покраснение снизу вверх, вуаль) → блеск (перелив, мягкий проход, полоса, белые дуги, искры обода) → сияние и ручейки слёз → лицо (глаза с веками, морфящийся рот) → румянец ///, щёчки, капля пота, венка, z z, звёздочки обода, искорки. Всё лежит внутри группы сжатия, поэтому эффекты прыгают и сплющиваются вместе с монетой, а румянец, слёзы и капля ещё и ездят вместе с лицом.

Состояние — набор каналов «элемент.атрибут»: d контуров, opacity слоёв и эффектов, translate/rotate/scale. Переходы на этой странице — интерполяция тех же чисел через setAttribute (CSS-свойство d не используется). Сцены — SMIL.
