# Дизайн-код Копейки · v1

Утверждён владельцем 18 октября 2026. По нему переделывается интерфейс — этап «v0.9 · Дизайн v1», эпик #160.

- **Этот файл** — правила: токены, шкалы, иконки, компоненты, паттерны, состояния, тексты.
- **[`v1.css`](v1.css)** — те же токены и компоненты в CSS. Этим кодом нарисованы макеты.
- **[`screens/`](screens)** — рендеры 24 экранов (390 px, ×2): эталон компоновки.
- **Холст** с «Как сейчас» и v1 рядом: [claude.ai/artifact/HHWPpvqerihPHh5bCBPYqo](https://claude.ai/artifact/HHWPpvqerihPHh5bCBPYqo) (доступ у владельца).

**Маскот в v1 не входит.** Где и как показывать Копейку, решаем в #21. На её местах — нейтральные эмблемы.

## Как пользоваться

1. Экран собирается только из компонентов и паттернов этого файла. Цвета, размеры шрифта, отступы и радиусы — только из токенов.
2. Нужен новый компонент или значение вне шкалы — сначала дополняем дизайн-код (этот файл, `v1.css`, каталог), потом делаем экран.
3. После #147 источник правды в коде — `web/src/tokens.css`, `web/src/ui.tsx`, `web/src/icons.tsx` и каталог компонентов `#/kit` (открывается с `?dev=1`). Этот файл описывает правила и имена. Если код и файл разошлись, правим то, что неверно, и обновляем второе.
4. Задачи ссылаются на компоненты по именам: «карточка долга — `DebtCard`», а не «как на картинке».

## 1. Принципы

- **Родной Telegram.** Фон, секции, текст, ссылки и кнопки — из темы Telegram. Нижняя кнопка — `MainButton`, вне Telegram её рисует заглушка.
- **Иконки вместо эмодзи.** В интерфейсе — только `Icon`. Эмодзи остаются в сообщениях бота и в CSV.
- **Главное наверху.** Баланс и действие к нему — в шапке группы. На «Балансах» первыми идут переводы, которые касаются вас.
- **Цвет несёт смысл.** Зелёный — вам должны и «сходится». Красный — вы должны, удаление, ошибка. Цвет категории — только в плитке и в полосе статистики. Медь — достижения, титулы, плашка «пример». Кнопки — цвета темы.
- **Числа ровные.** Деньги — моноширинные цифры (`tabular-nums`), без переноса, через `Money`.
- **Нажимается — значит 44 px.** Всё, что нажимается, не меньше 44×44, строка списка — от 52.

## 2. Токены

### Цвет

Базовые токены берутся из темы Telegram, производные считаются через `color-mix`. В скобках — запасные значения вне Telegram (светлая / тёмная). Полный список — в начале `v1.css`.

| Токен | Источник | Для чего |
|---|---|---|
| `--bg` | `--tg-theme-secondary-bg-color` (#efeff4 / #000) | фон экрана |
| `--sec` | `--tg-theme-section-bg-color` (#fff / #1c1c1e) | секции, карточки, поля |
| `--text` | `--tg-theme-text-color` | основной текст |
| `--hint` | `--tg-theme-hint-color` (#8e8e93 / #98989e) | подписи, плейсхолдеры, неактивное |
| `--sub` | `--tg-theme-section-header-text-color` (#6d6d72 / #8d8d93) | заголовки секций, вторичный текст |
| `--link` | `--tg-theme-link-color` (#2481cc / #3e88f7) | ссылки, иконки действий, фокус |
| `--btn`, `--btn-text` | `--tg-theme-button-color`, `--tg-theme-button-text-color` | основная кнопка, выбранное |
| `--sep` | `--tg-theme-section-separator-color` | разделители строк |
| `--neg` | `--tg-theme-destructive-text-color` (#d70015 / #ff453a) | вы должны, удаление, ошибка |
| `--pos` | свой (#1f8a3b / #30d158) | вам должны, «сходится» |
| `--line`, `--line2` | `color-mix(--hint)` | рамки чипов и полей; обводка радио и галочек |
| `--fill`, `--fill2` | `color-mix(--hint 12–36 %)` | поля, вторичные кнопки, трек сегментов и переключателя |
| `--tint` | `color-mix(--link 12–20 %)` | кнопка-подсказка, выбранный чип, ореол фокуса |
| `--press` | `color-mix(--hint 16–28 %)` | фон строки при нажатии |
| `--pos-tint`, `--neg-tint` | `color-mix(--pos / --neg)` | фон блока баланса |

| `--scrim` | чёрный 40 / 60 % | затемнение под модалкой |

Цвета категорий и медь — исключение из правила «только переменные темы»: они заданы парами для светлой и тёмной темы. Тёмная пара включается по `Telegram.WebApp.colorScheme`, вне Telegram — по `prefers-color-scheme`.

Аватары — прежние семь цветов, чуть темнее для контраста белых инициалов: `.a1`…`.a7`, цвет выбирается по id участника.

## 4. Компоненты

API — для `web/src/ui.tsx`. Класс в скобках — как в `v1.css`.

**Каркас**
- `Screen` (`.pg`) — колонка с отступами `--sp-4` по бокам, `--sp-6` между секциями. Вариант `dense` — `--sp-4` между блоками (экран группы). Снизу оставляет место под нижнюю панель.
- `ScreenTitle` (`.ttl`) + необязательный `lead` (`.lead`) — заголовок экрана и подзаголовок.
- `Section title aside footer inset` (`.sec`, `.st`, `.sb`, `.sf`) — секция. `aside` — ссылка или сумма справа в заголовке. `inset` — отступ разделителей: 16 по умолчанию; 52, 60, 64 или 68, когда слева аватар или плитка.
- `Card` (`.card`) — поверхность с отступом `--sp-4`, когда содержимое не список.

**Строки и элементы**
- `Row left title subtitle right chevron onClick tone` (`.row`) — строка списка. `tone`: `link` (синий текст, «Добавить…»), `danger` (красный). Длинный заголовок обрезается, с `wrap` — переносится (история). Правая колонка `RowValue amount caption` (`.rr`) — сумма и подпись 13 px.
- `Tile icon|text tone size` (`.tile`) — плитка. `tone`: категория (`food`…`other`) — цветная иконка на фоне 15 %; `link`, `brand`, `pos`, `neg`; `solid-blue | orange | green | purple | gray | red` — белая иконка на цвете (настройки). Буква группы — `text` на цвете аватара.
- `Avatar member size badge` (`.av`) — `badge`: значок действия малой плиткой 18 px в правом нижнем углу с обводкой цветом секции (история). `AvatarStack` (`.stack`) — с наложением 8 px и обводкой цветом секции.
- `Badge tone` (`.badge`) — `link`, `brand` (титулы, «пример»), `gray`.
- `Emblem icon tone size` (`.emb`) — круг 72 или 88 с иконкой: пустые состояния, приглашение, итоги, праздник.
- `Money value currency signed` — без изменений, только с токенами цвета.

**Кнопки и выбор**
- `Button variant size wide icon disabled loading` (`.btn`): `primary` — цвет темы, главное действие в карточке; `tint` — подсказка и действие по умолчанию рядом с вторичным («Отметить перевод», «Скопировать»); `fill` — вторичное («Изменить», «Не сейчас», «Отмена»); `ghost` — текстовое («Записать перевод вручную», «Ввести вручную»). `size="s"` — 36. Две кнопки рядом — поровну по ширине.
- `IconButton icon label variant` (`.ibtn`): `plain`, `fill` (настройки группы), `mute` (крестик, карандаш). `label` обязателен — это `aria-label`.
- `MainButton` — нижняя кнопка Telegram. Заглушка вне Telegram (`.mbar`, `.mbtn`): 52 px, радиус 12. Над ней может стоять одна текстовая кнопка (`ghost`).
- `Segmented` (`.seg`) — 2–3 варианта, равные доли.
- `Switch on` (`.sw`), `Check on` (`.chk`), `Radio on` (`.radio`), `Stepper value min max` (`.stp`).
- `Chip selected icon avatar dashed` (`.chip`) — выбор категории, участника, действие (`dashed`, «Разбить на 2 шт.»). Чипы переносятся по строкам, а не прокручиваются.

**Поля**
- `FieldRow label` (`label.row` + `input`) — подпись слева 104 px, поле справа (реквизиты).
- `BigField label` (`.blk` + `input`) — подпись 13 px над крупным полем 17 px (название группы, заведение).
- `Box` (`.box`) — поле суммы в строке позиции, 40 px, `--fill`.
- `QuickInput` (`.quick`) — поле 48 с иконкой `bolt`; в фокусе — рамка `--btn` и ореол `--tint`.
- Выбор («Кто платил», «Когда», «Повторять», «Валюта») — строкой `Row` со значением справа и шевроном; сам выбор — нативный контрол.

## 5. Паттерны

- `GroupHeader` — `Card`: название (`title-m`), «N участников · потрачено X», `IconButton` настроек; под ним `BalanceBlock` и `GroupActions`. Одинаков на всех вкладках.
- `BalanceBlock` (`.bal`) — «Вам должны / Вы должны / Вы в расчёте» и сумма `amount`. Фон `pos-tint`, `neg-tint` или `fill`. Справа `Button s` — «Напомнить» или «Рассчитаться». В расчёте — `Tile pos` с галочкой слева.
- `GroupActions` (`.acts`) — 2–3 плитки 60 px: иконка над подписью. У «Итоги» — счётчик достижений медью.
- `DemoNote` (`.note`) — плашка «пример»: медный фон, `Tile brand info`, текст, `Button s` «Удалить» красным.
- `DayHeader` — заголовок секции дня с суммой трат за день справа.
- `ExpenseRow` — `Row` с `Tile` категории, «Платил(а) X», справа сумма и «доля X» или «вы не участвуете».
- `QuickPreview` — `Card`: плитка, «Категория · сумма», хвост, две кнопки `primary` и `fill` поровну.
- `DebtCard` — `Card` из строки (аватар, имя, «должен(на) вам» / «вы должны», сумма `title-m`) и ряда кнопок `tint` + `fill`; под ними причина, если действие недоступно. Для своих долгов — реквизиты строками с `IconButton copy`.
- `BalanceTrack` (`.track`) — полоса с чертой посередине: вправо зелёная, влево красная.
- `CategoryStat` — `Row` с малой плиткой, названием и суммой, под ними полоса цвета категории.
- `StackBar` + легенда — сводная полоса категорий в итогах.
- `Fact` (`.fact`) — плитка факта: малая плитка, подпись, значение `title-m`, сумма.
- `Medal` (`.medal`) — достижение: получено — медь с обводкой; не получено — серое с прогрессом.
- `AmountCard` — `Card`: «Сумма», число `display`, валюта плашкой; название под чертой; необязательная строка «Разобрать чек».
- `EmptyState` — `Emblem`, заголовок `headline`, подсказка `hint`.
- `CelebrationModal` (`.modal` на `.scrim`) — эмблема 88, заголовок `title-m`, текст, `Button primary wide`, `Button ghost wide`.
- `FinishBanner` — `Card` с обводкой `--brand`: плитка-галочка, заголовок, текст, две кнопки поровну.
- `OkLine` (`.ok`) — зелёная галочка с текстом «сходится».

## 6. Состояния

- **Нажатие:** строка — фон `--press`; кнопки, чипы, плитки — `brightness(.94)`.
- **Фокус с клавиатуры:** обводка 2 px `--link`, отступ 2 px.
- **Неактивно:** прозрачность 45 %, без реакции. Если причина не очевидна, она написана рядом («… не подключил(а) уведомления»).
- **Загрузка:** экран — `Loading` по центру; кнопка — `loading` (у `MainButton` — родной индикатор); список «Показать ещё» — кнопка `ghost` неактивна, пока грузится.
- **Ошибка:** поле — обводка `--neg` и текст 13 px под полем (`.err`); экран — `EmptyState` с эмблемой и текстом ошибки; действие — диалог Telegram с текстом от API.
- **Пусто:** `EmptyState` с подсказкой, что сделать.
- **Движение:** анимации короткие (до 200 мс), при `prefers-reduced-motion` — без них.

| Пример | ссылка «Удалить пример» | кнопка «Удалить» в плашке |

## 8. Доступность

- Нажимаемое — настоящие `button`, `a`, `input` с `label`; у кнопок-иконок — `aria-label`.
- Цели касания от 44×44, строки от 52.
- Контраст текста от 4.5:1, крупного (от 22 px) — от 3:1, в обеих темах; текст на `--tint`, `--brand-tint` и плашках проверить отдельно.
- Смысл не держится только на цвете: у долга есть знак и слова «вы должны / вам должны», у полос — подпись.
- Декоративные иконки — `aria-hidden`; эмблемы с смыслом — `role="img"` и подпись.
